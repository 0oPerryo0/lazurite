# Lazurite

Unofficial read-only viewer for charts recovered from the Crystallium demo. Not affiliated with Studio Lycanthrope.

## Run locally

Requires Node.js 18+. No install step.

```powershell
node server.mjs
```

Open **http://127.0.0.1:4174/**. Do not open `index.html` directly.

```powershell
node --test *.test.js
```
